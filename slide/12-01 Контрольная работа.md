# Контрольная работа

---
## Задания
- Дан фрагмент на языке программы C++. Нужно построить атрибутивную грамматику описывающую синтаксически управляемую трансляцию в трехадрессный код для аналогичных конструкций
- Построить цепочку связей между понятиями

---
## Пояснения к заданию 1
- Атрибутивная грамматика
- Синтаксически управляемая трансляция
	- Семантический анализ
	- Генерация промежуточного кода
- Трехадрессный код

---
## Пример задания 1
```
int a = 5, b;
scanf("%d", &b)
if (b == a) {
	printf("test");
} else {
	a = b / 3 + 7;
}
```
